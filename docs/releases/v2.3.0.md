# CodexTracker 2.3.0 — Custom module order and reset expiry markers

Arrange your dashboard to match the services you use most, and see upcoming banked reset expiries directly on the weekly quota bar.

## Custom module order

- Move ChatGPT / Codex, Antigravity and other modules using the drag handle in each module header.
- Use the up/down buttons as an alternative, including with the keyboard.
- Move modules across subscription and API categories. Category headings follow the displayed order.
- Your layout is saved automatically and restored after restarting the app. Disabled modules retain their saved position when enabled again.
- If saving fails, the previous order stays in place and an error message lets you retry.

## Banked reset expiry markers

- Upcoming banked reset expiries now appear on the ChatGPT / Codex weekly bar, positioned on its reset-anchored time scale.
- Hover over or focus a marker to see the reset credit and its expiry time.
- Markers use the existing urgency colors, including yellow within 72 hours and red within 24 hours.
- Only available credits with a known upcoming expiry within the current weekly window receive a marker. Credits outside that window remain in the reset-credit list.

## Upgrading from 2.2.0

Quit CodexTracker completely, including its tray process, then replace the previous executable with `CodexTracker-2.3.0.exe`. Existing settings, saved credentials and local history are preserved. Existing installations keep their previous module order until you rearrange it.
