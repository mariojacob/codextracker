# CodexTracker 2.4.1 — Windows taskbar icon and simpler one-time resets

- Fix Windows taskbar identity for the portable application. The main window and statistics window now explicitly identify the original executable for their taskbar icon and relaunch command.
- Replace the old PNG-only ICO frames with Windows bitmap frames at common taskbar and display scaling sizes, fixing the generic application symbol returned by the Windows shell.
- Ship runtime icon files outside the application archive and verify that Windows extracts the correct CodexTracker icon during packaging.
- Simplify manual reset entry to a single date and time. The editor explicitly labels the deadline as **one-time, with no repetition** and no longer asks you to select a weekly or monthly quota.
- Select the module's main quota automatically. Existing saved quota choices and deadlines remain compatible.
- Continue to support editing or removing the date and switching between automatic and manual display. Expired deadlines return to automatic display; no new date is scheduled.

Manual dates align the pace marker and daily budget with your planned deadline. They do not perform a provider reset or redeem a reset credit.

## Upgrade

Quit CodexTracker completely, including its tray process, then replace the previous executable with `CodexTracker-2.4.1.exe`. Existing settings, saved deadlines, credentials and history are preserved.
