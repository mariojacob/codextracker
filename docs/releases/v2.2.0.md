# CodexTracker 2.2.0 — More providers, clearer limits

CodexTracker now brings multiple AI services into the same compact Windows app, with clearer daily budgets and separate statistics for each module.

## New provider modules

- **Subscriptions & Coding Plans:** ChatGPT / Codex, Antigravity, Claude, Cursor, Grok / SuperGrok, MiniMax, z.ai / GLM and Kimi Code.
- **API balances & reported spend:** DeepSeek, Moonshot, xAI and Anthropic, clearly separated from subscription quotas.
- Enable or disable every module in **Settings → Providers & modules**, including Codex itself. Additional providers are off by default and work independently of Codex sign-in.
- Credentials are stored separately by provider and region in Windows Credential Manager.

## Clearer quota planning

- Quota bars grow with consumption and show both used and remaining percentages.
- Weekly bars have seven budget-day segments, a highlighted current day and a white marker for an even consumption pace.
- Daily allowances follow the reset time. Unused allowance carries forward within the week; excess usage reduces the remaining allowance.
- Banked resets are sorted by expiry. Yellow highlights indicate expiry within 72 hours; red highlights indicate expiry within 24 hours.

## Statistics for each module

- Choose the provider, region and individual model quota or currency you want to inspect.
- Compare the current and previous day with 7-/30-day histories and charts.
- Quota consumption uses comparable measurements within the same reset window. Resets and missing readings do not become artificial consumption.
- API balances show observed decreases, increases and daily last-reading trends. Reported costs retain their provider-defined period and are never summed across snapshots.
- Visible gaps and incomplete totals make interrupted tracking explicit. The open statistics window updates when new measurements are saved.

## Other changes

- Removed the reset forecast and its external polling, settings, tray entries and notification rules.
- Updated Electron from 43.1.1 to **43.8.0**.
- Updated English/German texts, setup documentation and README screenshots. All promotional screenshots use simulated data.

## Upgrading from 2.1.0

Quit the previous app completely, including its tray process, then replace it with `CodexTracker-2.2.0.exe`. Existing settings and history remain local; obsolete forecast settings are migrated automatically. Additional modules begin collecting their own history when enabled. Older Codex history without reliable reset metadata is preserved but is not used to reconstruct daily consumption.

Some integrations depend on private provider endpoints and require specific credential types or account plans. See the [provider setup guide](https://github.com/mariojacob/codextracker/blob/main/docs/providers.md).
