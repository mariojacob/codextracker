# CodexTracker 2.4.3 — One-time resets and a restored taskbar icon

Know when your next reset will happen? Enter that date once and plan your remaining usage around it. This release also restores the correct Windows taskbar icon for the portable app.

## One-time reset planning

- Enter a date and time directly inside a quota module. The deadline uses your local timezone and applies once, with no weekly or monthly repetition.
- The main quota is selected automatically, so the editor only asks for the date and time. Existing saved quota choices remain compatible.
- Choose **Display → Manual reset** to align the pace marker, budget-day segments and daily allowance with your deadline. Switch back to **Automatic** whenever you want.
- A purple marker identifies the manual reset on the quota bar. In automatic mode, it appears when the deadline falls within the provider's current reset window.
- Edit or remove the date at any time. Saved deadlines and display choices survive a restart; expired deadlines return to automatic display until updated.
- English and German controls are supported, including in the compact window layout.

Manual dates are planning aids. They do not trigger a provider reset or redeem a reset credit. Actual consumption and statistics continue to come from provider data. Modules that only report balances or expenses do not have quota reset controls.

## Windows taskbar icon fixed

- Restore the green CodexTracker icon in the Windows taskbar instead of the generic application symbol.
- Keep icon resources available across portable app restarts and executable updates.
- Use consistent Windows grouping for the main and statistics windows.

## Upgrade

Quit the previous version completely, including its tray process, then replace it with `CodexTracker-2.4.3.exe`. Settings, saved reset dates, module order, credentials and local history are preserved. If you pinned an earlier version, replace that pin with the new executable.
