# CodexTracker 2.4.4 — Plan until the next banked reset

Plan your Codex usage around the next banked reset that expires, with a new option directly in the module's Display menu.

## Next banked reset

- Choose **Display → Next banked reset** in ChatGPT / Codex. In German, choose **Anzeige → Nächster Banked Reset**.
- The weekly allowance, daily budget and pace marker use the earliest known expiry of an available banked reset as their planning deadline.
- When a reset expires or is redeemed, the deadline follows the next available reset. Used resets and unknown or invalid expiry dates are skipped.
- If no upcoming expiry is known, the automatic weekly budget is shown. The saved preference remains selected so planning resumes when a suitable reset becomes available.
- Switch between **Automatic**, **Manual reset** and **Next banked reset** at any time. The preference survives a restart, and saved manual deadlines remain available.

This is a planning display. It does not redeem reset credits or trigger a reset automatically. Consumption and statistics continue to use provider readings.

## Updated README screenshots

Four new screenshots show the current dashboard, quota statistics, API balance history and module selection with dummy data. Direct app views replace the previous promotional headings and explanation panels, with substantially less text around the interface.

## Upgrade

Quit the previous version completely, including its tray process, then replace it with `CodexTracker-2.4.4.exe`. Settings, saved reset dates, module order, credentials and local history are preserved. If you pinned an earlier executable, replace that pin with the new version.
